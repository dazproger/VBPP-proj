В работе был рассмотрен новый метод упаковки контейнеров - Simple Variance, в котором на каждом шаге классичских Bin Centric алгоритмов минимизируется выборочная дисперсия координат контейнера. 
Метод дает интересные результаты при предметах, приходящих из равномерного распределения. 
Код нужен для построения графиков из презентации и работы (проверки эффективности алгоритма, в сравнении с классическими FFD/Geometry алгоритмами).
